# DocTransform AI

Beginner-friendly full-stack starter for **DocTransform AI – Intelligent Document Transformation & Action Intelligence Platform**.

## Project structure

- `frontend/` — React, Vite, and Tailwind CSS user interface.
- `backend/` — Python and FastAPI API service.

## Current scope

This repository currently contains only the project skeleton. No authentication, database, OCR, LLM, or action-intelligence functionality has been added.
